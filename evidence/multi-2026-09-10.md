## Recipe notes (failures hit before success — kept for the runbook)

1. CLI vec-of-struct args need `--<arg>-file-path` AND i128 values as JSON
   STRINGS (`"scale_num":"1"`); bare numbers are rejected by the parser.
2. `--sign-with-key` is single-use in CLI 26.1.0; `--send=yes` with one key
   dies `Missing signing key for account <B>`.
3. `tx sign` chaining appends ENVELOPE signatures only: A+B → `TxBadAuthExtra`,
   B-only → `TxBadAuth`. Soroban needs ENTRY-level signatures.
4. Working path: `--build-only` → `scripts/two_signer_submit.js` (simulate +
   assemble + per-entry `authorizeEntry` + source envelope sign + send + poll).
